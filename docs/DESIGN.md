Approved visual reference: Higherlife Foundation (immersive media, editorial typography, cinematic transitions; no assets copied). Primary palette #102637, #0A1926, #C3A36B, #F5F1E8, #FFFFFF. Navy dominates; gold solid CTAs, restrained rectangular geometry. Original crest and portraits, homepage and founder content preserved. Display type: Cormorant Garamond 600; interface: Inter 400–600; Persian: Dana 400–600. Fonts are not bundled in the supplied source; local fallback Georgia, existing DM Sans and Vazirmatn, with one-time font installer. Confirm Dana licensing and actual rendered type before final visual sign-off.

## Public experience
Grand Academic Entrance: centered header, headline and existing introduction, complete film, prominent gold Explore the Journey underneath. On compact phones the complete introduction remains below the film/CTA for readability; natural overflow is intentional. The header has a centered brand lockup, discreet menu, language control and consultation action; compact screens keep consultation accessible through the drawer. The five public destinations are Home, Journey, Founders, Contact, Consultation. Calendar is a continuation of the form. Legacy routes and privacy retained; private dashboard separate. First-visit bilingual dialog remembers preference; explicit language URLs respected. Language switching preserves section and current journey stage. Main chapter transitions fade through navy over ~660 ms rather than swipe. No loading splash.

## Golden Path
Six milestones: Discovery, Assessment, Strategy, Development, Progress, Destination. Desktop ascending/winding SVG; portrait vertical SVG; active node, progressive gold line, traveling light. Auto progresses every 10 seconds when visible and not paused; manual arrows, stage buttons, horizontal swipe, keyboard arrows. Manual interaction pauses auto; destination stops, Resume restarts. Reduced motion static with manual navigation. Back to beginning, destination consultation CTA. Native scrolling for content that exceeds viewport; wheel/swipe chapter changes at boundaries only.
